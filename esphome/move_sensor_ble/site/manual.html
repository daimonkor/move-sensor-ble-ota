Move Sensor BLE — user manual

Battery motion sensor with temperature and humidity for Home Assistant. Sends data over Bluetooth (BTHome) and sleeps in between; Wi-Fi is used for setup and can also be a data channel when powered from USB.

1What's on the case

PartPurpose
PWR switch (left wall, SW1)Turns the sensor on and off (battery).
WiFi switch (right wall, SW2)Service mode. On — the sensor stays awake, turns on Wi-Fi, its own access point and web page. Off — normal mode, sleeps and sends data over Bluetooth.
Blue LED (lid)Shows motion events and confirmations — see section 4.
USB-CCharging the battery and power from USB.
Vents with T/RH markTemperature and humidity sensor — do not cover.

Every sensor has its own Device ID — 6 characters, e.g. 148F98. You will see it in Home Assistant, in the access point name MoveSensorBLE-148F98 and on the ID sticker.

2Operating modes

ModeHowWhat happens
NormalWiFi switch offSleeps; wakes on motion and on the climate timer, sends data over Bluetooth, sleeps again. Wi-Fi is completely off — longest battery life.
ServiceWiFi switch onDoesn't sleep. Wi-Fi to your router, own access point, web page, ESPHome firmware updates. Data also goes to Home Assistant over Wi-Fi.
USB + Wi-FiUSB-C connected, WiFi onFor homes without Bluetooth proxies: the sensor works permanently over Wi-Fi without draining the battery.

The mode follows only the WiFi switch position — also after a power loss.

On battery, do not leave the WiFi switch on: the sensor does not sleep and the battery drains in about a day. The sensor web page reminds you about this.

3Adding to Home Assistant

  1. Install the Move Sensor BLE OTA integration (Marketplace → add repository daimonkor/move-sensor-ble-ota) and restart Home Assistant.
  2. Switch the sensor on (PWR) and add the integration — pick the sensor by its Device ID. The integration reads the sensor's Bluetooth packets itself; a separate BTHome integration is not needed. A Bluetooth adapter or ESPHome Bluetooth proxy within reach is needed.
  3. Optional, for the Wi-Fi channel: turn WiFi on — Home Assistant discovers the ESPHome device Move Sensor BLE <ID>; add it.

Main entities: Occupancy, Temperature, Humidity, Battery, Voltage, signal strength. The integration adds settings, firmware update, Device ID, Last seen, battery days left and statistics.

4LED signals

LEDMeaning
1 flashMotion detected — "occupied" sent.
2 flashesArea clear — "clear" sent (after Keep time).
3 slow flashesWiFi switch turned on — service mode.
2 short flashesSwitch turned on again within 10 s — 2nd turn counted toward the factory reset (the 3rd resets).
6 fast flashesReset command accepted (switch sequence or command from Home Assistant).
Fast blinking for 10 sIdentify — pressed in Home Assistant to find this particular sensor.

Motion flashes can be turned off with the Motion tracking LED setting; service mode, confirmations and Identify always blink.

5Settings

Change them in Home Assistant on the Move Sensor BLE device (sent over Bluetooth). The sensor applies them at its next wake-up — the status shows pending until then, then applied. Wave in front of the sensor to wake it.

SettingDefaultWhat it does
Detect delay100 msHow long motion must last to count. Raise it if there are false triggers.
Keep time30 sHow long "occupied" is held after motion stops (5–600 s).
Climate report interval5 minHow often temperature and humidity are sent (0 = off). More often = shorter battery life.
Temperature / Humidity offset0Correction if the sensor reads higher or lower than a reference thermometer. Humidity is recalculated automatically.
Motion tracking LEDonFlash on motion events.
Motion refresh interval2 minWhile occupied and someone keeps moving, "occupied" is repeated at most this often (1–60 min).
Motion / Climate windowautoHow long the sensor transmits per event. Picked automatically by signal strength (Auto advertising window); longer = more reliable delivery, shorter = longer battery life.
Voltage factorcalibratedBattery voltage calibration; change only with a multimeter.
When the sensor works over Wi-Fi only (USB + WiFi on), change settings on the ESPHome device in Home Assistant or on the sensor web page.

6Sensor web page

Available only with the WiFi switch on.

  • Through the sensor's own access point: on your phone connect to Wi-Fi MoveSensorBLE-<ID> and open http://100.64.4.1/. The .local address does not work here.
  • From your home network: http://move-sensor-ble-<id>.local (lowercase ID) or the sensor's IP address (shown on the page and in Home Assistant).

The Sensor tab shows motion, temperature, humidity, battery, signal and device info. The Device tab is the standard ESPHome interface with all controls and the log. The Wi-Fi icon in the top bar opens network and access point settings; EN/UA/RU switches the language, ? opens this manual.

Keep only one or two pages of the sensor open at a time — each open page uses one of the sensor's few network connections.

7Connecting to your Wi-Fi router

  1. WiFi switch on, open the sensor page (via its access point if it has no router connection yet).
  2. Tap the Wi-Fi icon → Find networks → pick your network, enter the password → Connect to network.
  3. If it cannot connect within 20 s, the sensor automatically returns to the previous network.

Firmware network returns to the network built into the firmware.

8Access point password

The sensor's own access point MoveSensorBLE-<ID> has a default password. You can set your own:

  1. Sensor page → Wi-Fi icon → Sensor access point password.
  2. Enter a new password: 8–63 characters, Latin letters, digits and symbols only (no Cyrillic).
  3. Tap Change AP password twice (confirmation). A green message confirms it.
  4. The sensor reboots (~5 s). Your phone disconnects — connect again with the new password.
On the Device tab (standard interface) or in Home Assistant: type the password into New AP password, press Enter, then Save AP password. If you press Save without Enter, the field is still empty.

If the password is not accepted you will see the reason: a red message on the page, the AP password status sensor (e.g. rejected: 5 characters, need 8-63) and, if allowed, a notification in Home Assistant. The AP password sensor shows default or custom.

Forgot your password? Use the factory reset (section 9).

9Factory reset

Restores the router network from the firmware and the default access point password. Other settings (Keep time etc.) are kept.

  1. Start with the WiFi switch off (if it is on — switch it off).
  2. Switch WiFi on — the LED flashes 3 times slowly: service mode, counting starts.
  3. Off and on again — 2 short flashes: the 2nd turn is counted.
  4. Off and on the 3rd time — 6 fast flashes: reset done. Leave it on.
  5. The sensor reboots (~2 s) — 3 slow flashes again — and brings up its access point with the default password (on the sticker).
You seeMeans
3 slowService mode on; count = 1. On the 2nd or 3rd turn this means the 10 s ran out and counting started over — switch off and continue from step 3.
2 short2nd turn counted.
6 fastReset done, reboot follows.

All three turns within 10 seconds from the first "on" to the third. The off position between them can be short (about a second is enough).

From Home Assistant: the Reset Wi-Fi to default (BLE) button. The sensor confirms with 6 fast flashes when it receives the command; the reset itself is applied the next time WiFi is switched on — 6 fast, reboot, 3 slow.

10Battery and charging

  • LiPo 920 mAh with its own protection board. Charge via USB-C; the sensor keeps working while charging.
  • Battery shows %; at 10 % or less it is time to charge (the sensor page marks it as low battery); the integration also estimates battery days left.
  • The battery connector can be unplugged. Mind the polarity labels on the battery and the board.
  • Firmware update over Bluetooth is refused below 30 % so the sensor cannot switch off mid-update — charge first.

11Firmware updates

  • Over Bluetooth (normal mode): Home Assistant → Settings → Updates → Move Sensor BLE firmware → Install (it appears when the firmware files changed). The integration builds this sensor's firmware and flashes it at the next wake-up; progress is shown on the update card.
  • Over Wi-Fi (WiFi on): ESPHome Builder → Move Sensor BLE <ID> → Install → Wirelessly.

If a new firmware fails right after start, the sensor rolls back to the previous one automatically.

12Troubleshooting

ProblemWhat to do
Motion reported with nobody thereKeep the sensor away from heaters, sunlight and drafts; raise Detect delay. The hidden Debug section of the page (tap the footer 5 times) shows raw PIR pulses.
Temperature too highCheck against a reference after 20–30 min with WiFi off and USB unplugged, then set Temperature offset.
Page does not open via the access pointUse http://100.64.4.1/, not .local. Check that the WiFi switch is on.
Can't join the access pointPassword changed and forgotten → factory reset (section 9).
Password not accepted8–63 Latin characters; on the Device tab press Enter before Save. See AP password status.
Settings stay "pending"The sensor is asleep — wave in front of it, or wait for the next climate report.
Bluetooth update refusedBattery below 30 % — charge it, or update over Wi-Fi.
No data in Home AssistantCheck PWR, battery, and that a Bluetooth adapter/proxy is in range (signal strength).

Move Sensor BLE — інструкція користувача

Батарейний датчик руху з температурою та вологістю для Home Assistant. Передає дані по Bluetooth (BTHome) і спить між подіями; Wi-Fi потрібен для налаштування, а від USB може бути й каналом даних.

1Що на корпусі

ЕлементПризначення
Перемикач PWR (ліва стінка, SW1)Вмикає й вимикає датчик (живлення від батареї).
Перемикач WiFi (права стінка, SW2)Сервісний режим. Увімкнено — датчик не спить, вмикає Wi-Fi, власну точку доступу та сайт. Вимкнено — звичайний режим: спить і передає дані по Bluetooth.
Синій світлодіод (кришка)Показує спрацювання та підтвердження — див. розділ 4.
USB-CЗаряджання батареї та живлення від USB.
Отвори з позначкою T/RHДатчик температури й вологості — не закривати.

Кожен датчик має свій Device ID — 6 символів, наприклад 148F98. Його видно в Home Assistant, у назві точки доступу MoveSensorBLE-148F98 і на наклейці з ID.

2Режими роботи

РежимЯк увімкнутиЩо відбувається
ЗвичайнийWiFi вимкненоСпить; прокидається від руху та за таймером клімату, передає дані по Bluetooth і знову засинає. Wi-Fi повністю вимкнений — найдовша робота від батареї.
СервіснийWiFi увімкненоНе спить. Wi-Fi до роутера, власна точка доступу, сайт, оновлення прошивки через ESPHome. Дані йдуть у Home Assistant також по Wi-Fi.
USB + Wi-FiПідключено USB-C, WiFi увімкненоДля будинку без Bluetooth-проксі: датчик постійно працює по Wi-Fi, не розряджаючи батарею.

Режим залежить лише від положення перемикача WiFi — і після зникнення живлення теж.

Від батареї не залишайте WiFi увімкненим: датчик не спить, і батарея сяде приблизно за добу. Сайт датчика про це нагадує.

3Додавання в Home Assistant

  1. Встановіть інтеграцію Move Sensor BLE OTA (Marketplace → додати репозиторій daimonkor/move-sensor-ble-ota) і перезапустіть Home Assistant.
  2. Увімкніть датчик (PWR) і додайте інтеграцію — оберіть датчик за Device ID. Інтеграція сама читає Bluetooth-пакети датчика, окрема інтеграція BTHome не потрібна. Потрібен Bluetooth-адаптер або Bluetooth-проксі ESPHome поруч.
  3. За бажанням, для каналу Wi-Fi: увімкніть WiFi — Home Assistant знайде пристрій ESPHome Move Sensor BLE <ID>; додайте його.

Основні сутності: Occupancy, Temperature, Humidity, Battery, Voltage, рівень сигналу. Інтеграція додає налаштування, оновлення прошивки, Device ID, Last seen, прогноз днів роботи батареї та статистику.

4Сигнали світлодіода

СвітлодіодЗначення

2 спалахиВільно — надіслано «вільно» (після Keep time).
3 повільні спалахиУвімкнули перемикач WiFi — сервісний режим.
2 короткі спалахиПеремикач увімкнули знову протягом 10 с — 2-ге ввімкнення зараховано до заводського скидання (3-тє скидає).

Спалахи на рух вимикаються налаштуванням Motion tracking LED; сервісний режим, підтвердження та Identify блимають завжди.

5Налаштування

Змінюються в Home Assistant на пристрої Move Sensor BLE (передаються по Bluetooth). Датчик застосовує їх під час наступного пробудження — до того статус pending, потім applied. Помахайте перед датчиком, щоб розбудити його.

НалаштуванняЗа замовчуваннямЩо робить
Detect delay100 мсСкільки має тривати рух, щоб його зарахувати. Збільште, якщо є хибні спрацювання.
Keep time30 сСкільки утримується «зайнято» після зникнення руху (5–600 с).
Climate report interval5 хвЯк часто надсилати температуру й вологість (0 = вимкнено). Частіше — менше працює батарея.
Temperature / Humidity offset0Поправка, якщо датчик показує більше чи менше за еталонний термометр. Вологість перераховується автоматично.
Motion tracking LEDувімк.Спалахи на спрацювання.
Motion refresh interval2 хвПоки «зайнято» і людина рухається, «зайнято» повторюється не частіше за цей інтервал (1–60 хв).
Motion / Climate windowавтоСкільки датчик передає на одну подію. Підбирається автоматично за рівнем сигналу (Auto advertising window); довше — надійніша доставка, коротше — довше працює батарея.
Voltage factorвідкаліброваноКалібрування напруги батареї; змінювати лише з мультиметром.
Якщо датчик працює лише по Wi-Fi (USB + WiFi увімкнено), налаштування змінюйте на пристрої ESPHome у Home Assistant або на сайті датчика.

6Сайт датчика

Доступний лише коли WiFi увімкнено.

  • Через власну точку доступу: на телефоні підключіться до Wi-Fi MoveSensorBLE-<ID> і відкрийте http://100.64.4.1/. Адреса .local тут не працює.
  • З домашньої мережі: http://move-sensor-ble-<id>.local (ID малими літерами) або IP-адреса датчика (є на сайті та в Home Assistant).

Вкладка Датчик — рух, температура, вологість, батарея, сигнал і дані пристрою. Вкладка Пристрій — стандартний інтерфейс ESPHome з усіма керуваннями та журналом. Значок Wi-Fi вгорі відкриває налаштування мережі та точки доступу; EN/UA/RU перемикає мову, ? відкриває цю інструкцію.

Тримайте відкритими одну-дві сторінки датчика — кожна відкрита сторінка займає одне з небагатьох мережевих з'єднань датчика.

7Підключення до роутера

  1. WiFi увімкнено, відкрийте сайт датчика (через його точку доступу, якщо до роутера ще не підключено).
  2. Значок Wi-Fi → Знайти мережі → оберіть мережу, введіть пароль → Підключитися до мережі.
  3. Якщо за 20 с не вдалося підключитися, датчик сам повернеться до попередньої мережі.

Мережа з прошивки повертає мережу, вбудовану в прошивку.

8Пароль точки доступу

Власна точка доступу датчика MoveSensorBLE-<ID> має заводський пароль. Можна встановити свій:

  1. Сайт датчика → значок Wi-Fi → Пароль точки доступу датчика.
  2. Введіть новий пароль: 8–63 символи, лише латинські літери, цифри та знаки (без кирилиці).
  3. Натисніть Змінити пароль точки двічі (підтвердження). Зелене повідомлення підтвердить зміну.
  4. Датчик перезавантажиться (~5 с). Телефон відключиться — підключіться знову з новим паролем.
На вкладці Пристрій (стандартний інтерфейс) або в Home Assistant: введіть пароль у New AP password, натисніть Enter, потім Save AP password. Без Enter поле ще порожнє.

Якщо пароль не прийнято, буде видно причину: червоне повідомлення на сайті, сенсор AP password status (наприклад rejected: 5 characters, need 8-63) і, якщо дозволено, сповіщення в Home Assistant. Сенсор AP password показує default або custom.

Забули пароль? Зробіть заводське скидання (розділ 9).

9Заводське скидання

Повертає мережу роутера з прошивки та заводський пароль точки доступу. Інші налаштування (Keep time тощо) зберігаються.

  1. Почніть з вимкненого WiFi (якщо увімкнено — вимкніть).
  2. Увімкніть WiFi — світлодіод блимне 3 рази повільно: сервісний режим, рахунок почався.
  3. Вимкніть і знову увімкніть — 2 короткі спалахи: 2-ге ввімкнення зараховано.
  4. Вимкніть і увімкніть втретє — 6 швидких спалахів: скидання виконано. Не вимикайте.
  5. Датчик перезавантажиться (~2 с) — знову 3 повільні — і підніме точку доступу із заводським паролем (на наліпці).
БачитеЗначить
3 повільніСервісний режим, рахунок = 1. Якщо це на 2-му чи 3-му ввімкненні — минули 10 с, рахунок почався спочатку: вимкніть і продовжуйте з кроку 3.
2 короткіЗараховано 2-ге ввімкнення.
6 швидкихСкидання виконано, далі перезавантаження.

Усі три ввімкнення — за 10 секунд від першого до третього. Вимкнене положення між ними може бути коротким (досить секунди).

З Home Assistant: кнопка Reset Wi-Fi to default (BLE). Отримавши команду, датчик відповідає 6 швидкими спалахами; саме скидання — при наступному ввімкненні WiFi: 6 швидких, перезавантаження, 3 повільні.

10Батарея та заряджання

  • LiPo 920 мА·год із власною платою захисту. Заряджання через USB-C; датчик під час заряджання працює.
  • Battery показує %; при 10 % і менше час заряджати (на сайті датчика — позначка низький заряд); інтеграція також оцінює battery days left.
  • Роз'єм батареї знімний. Зважайте на наклейки полярності на батареї та платі.
  • Оновлення прошивки по Bluetooth не виконується, якщо заряд нижче 30 %, щоб датчик не вимкнувся посеред оновлення — спершу зарядіть.

11Оновлення прошивки

  • По Bluetooth (звичайний режим): Home Assistant → Налаштування → Оновлення → Move Sensor BLE firmware → Встановити (з'являється, коли файли прошивки змінились). Інтеграція збере прошивку саме цього датчика й залиє її при наступному пробудженні; хід видно на картці оновлення.
  • По Wi-Fi (WiFi увімкнено): ESPHome Builder → Move Sensor BLE <ID> → Install → Wirelessly (у російському інтерфейсі «Установка» → «В сети»).

Якщо нова прошивка падає одразу після запуску, датчик автоматично повертається до попередньої.

Переключатель WiFi (правая стенка, SW2)Сервисный режим. Включён — датчик не спит, включает Wi-Fi, свою точку доступа и сайт. Выключен — обычный режим: спит и передаёт данные по Bluetooth.
Синий светодиод (крышка)Показывает срабатывания и подтверждения — см. раздел 4.
USB-CЗарядка батареи и питание от USB.
Отверстия с меткой T/RHДатчик температуры и влажности — не закрывать.

У каждого датчика свой Device ID — 6 символов, например 148F98. Он виден в Home Assistant, в имени точки доступа MoveSensorBLE-148F98 и на наклейке с ID.

2Режимы работы

РежимКак включитьЧто происходит
ОбычныйWiFi выключенСпит; просыпается от движения и по таймеру климата, передаёт данные по Bluetooth и снова засыпает. Wi-Fi полностью выключен — самая долгая работа от батареи.
СервисныйWiFi включёнНе спит. Wi-Fi к роутеру, своя точка доступа, сайт, обновление прошивки через ESPHome. Данные идут в Home Assistant и по Wi-Fi.
USB + Wi-FiПодключён USB-C, WiFi включёнДля дома без Bluetooth-прокси: датчик постоянно работает по Wi-Fi, не разряжая батарею.

Режим зависит только от положения переключателя WiFi — и после пропадания питания тоже.

От батареи не оставляйте WiFi включённым: датчик не спит, и батарея сядет примерно за сутки. Сайт датчика об этом напоминает.

3Добавление в Home Assistant

  1. Установите интеграцию Move Sensor BLE OTA (Marketplace → добавить репозиторий daimonkor/move-sensor-ble-ota) и перезапустите Home Assistant.
  2. Включите датчик (PWR) и добавьте интеграцию — выберите датчик по Device ID. Интеграция сама читает Bluetooth-пакеты датчика, отдельная интеграция BTHome не нужна. Нужен Bluetooth-адаптер или Bluetooth-прокси ESPHome рядом.
  3. По желанию, для канала Wi-Fi: включите WiFi — Home Assistant найдёт устройство ESPHome Move Sensor BLE <ID>; добавьте его.

Основные сущности: Occupancy, Temperature, Humidity, Battery, Voltage, уровень сигнала. Интеграция добавляет настройки, обновление прошивки, Device ID, Last seen, прогноз дней работы батареи и статистику.

Вспышки на движение отключаются настройкой Motion tracking LED; сервисный режим, подтверждения и Identify мигают всегда.

5Настройки

Меняются в Home Assistant на устройстве Move Sensor BLE (передаются по Bluetooth). Датчик применяет их при следующем пробуждении — до этого статус pending, потом applied. Помашите перед датчиком, чтобы разбудить его.

НастройкаПо умолчаниюЧто делает
Detect delay100 мсСколько должно длиться движение, чтобы его засчитать. Увеличьте при ложных срабатываниях.
Keep time30 сСколько держится «занято» после пропадания движения (5–600 с).
Climate report interval5 минКак часто отправлять температуру и влажность (0 = выключено). Чаще — меньше работает батарея.
Temperature / Humidity offset0Поправка, если датчик показывает больше или меньше эталонного термометра. Влажность пересчитывается автоматически.
Motion tracking LEDвкл.Вспышки на срабатывания.
Motion refresh interval2 минПока «занято» и человек двигается, «занято» повторяется не чаще этого интервала (1–60 мин).
Motion / Climate windowавтоСколько датчик передаёт на одно событие. Подбирается автоматически по уровню сигнала (Auto advertising window); дольше — надёжнее доставка, короче — дольше работает батарея.
Voltage factorоткалиброванКалибровка напряжения батареи; менять только с мультиметром.
Если датчик работает только по Wi-Fi (USB + WiFi включён), настройки меняйте на устройстве ESPHome в Home Assistant или на сайте датчика.

6Сайт датчика

Доступен только когда WiFi включён.

  • Через свою точку доступа: на телефоне подключитесь к Wi-Fi MoveSensorBLE-<ID> и откройте http://100.64.4.1/. Адрес .local здесь не работает.
  • Из домашней сети: http://move-sensor-ble-<id>.local (ID строчными) или IP-адрес датчика (есть на сайте и в Home Assistant).

Вкладка Датчик — движение, температура, влажность, батарея, сигнал и данные устройства. Вкладка Устройство — штатный интерфейс ESPHome со всеми управлениями и журналом. Значок Wi-Fi вверху открывает настройки сети и точки доступа; EN/UA/RU переключает язык, ? открывает эту инструкцию.

Держите открытыми одну-две страницы датчика — каждая открытая страница занимает одно из немногих сетевых подключений датчика.

7Подключение к роутеру

  1. WiFi включён, откройте сайт датчика (через его точку доступа, если к роутеру ещё не подключён).
  2. Значок Wi-Fi → Найти сети → выберите сеть, введите пароль → Подключиться к сети.
  3. Если за 20 с подключиться не удалось, датчик сам вернётся к прежней сети.

Сеть из прошивки возвращает сеть, встроенную в прошивку.

8Пароль точки доступа

У своей точки доступа датчика MoveSensorBLE-<ID> заводской пароль. Можно задать свой:

  1. Сайт датчика → значок Wi-Fi → Пароль точки доступа датчика.
  2. Введите новый пароль: 8–63 символа, только латинские буквы, цифры и знаки (без кириллицы).
  3. Нажмите Сменить пароль точки два раза (подтверждение). Зелёное сообщение подтвердит смену.
  4. Датчик перезагрузится (~5 с). Телефон отключится — подключитесь заново с новым паролем.
На вкладке Устройство (штатный интерфейс) или в Home Assistant: введите пароль в New AP password, нажмите Enter, затем Save AP password. Без Enter поле ещё пустое.

Если пароль не принят, будет видна причина: красное сообщение на сайте, сенсор AP password status (например rejected: 5 characters, need 8-63) и, если разрешено, уведомление в Home Assistant. Сенсор AP password показывает default или custom.

Забыли пароль? Сделайте заводской сброс (раздел 9).

9Заводской сброс

Возвращает сеть роутера из прошивки и заводской пароль точки доступа. Остальные настройки (Keep time и т. д.) сохраняются.

  1. Начните с выключенного WiFi (если включён — выключите).
  2. Включите WiFi — светодиод мигнёт 3 раза медленно: сервисный режим, счёт начался.
  3. Выключите и снова включите — 2 короткие вспышки: 2-е включение засчитано.
  4. Выключите и включите в 3-й раз — 6 быстрых вспышек: сброс выполнен. Не выключайте.
  5. Датчик перезагрузится (~2 с) — снова 3 медленные — и поднимет точку доступа с заводским паролем (на наклейке).
ВидитеЗначит
3 медленныеСервисный режим, счёт = 1. Если это на 2-м или 3-м включении — прошло больше 10 с, счёт начался заново: выключите и продолжайте с шага 3.
2 короткиеЗасчитано 2-е включение.
6 быстрыхСброс выполнен, дальше перезагрузка.

Все три включения — за 10 секунд от первого до третьего. Выключенное положение между ними может быть коротким (хватит секунды).

Из Home Assistant: кнопка Reset Wi-Fi to default (BLE). Получив команду, датчик отвечает 6 быстрыми вспышками; сам сброс — при следующем включении WiFi: 6 быстрых, перезагрузка, 3 медленные.

10Батарея и зарядка

  • LiPo 920 мА·ч со своей платой защиты. Зарядка через USB-C; во время зарядки датчик работает.
  • Battery показывает %; при 10 % и меньше пора заряжать (на сайте датчика — отметка низкий заряд); интеграция также оценивает battery days left.
  • Разъём батареи съёмный. Смотрите на наклейки полярности на батарее и плате.
  • Обновление прошивки по Bluetooth не выполняется при заряде ниже 30 %, чтобы датчик не выключился посреди обновления — сначала зарядите.

11Обновление прошивки

  • По Bluetooth (обычный режим): Home Assistant → Настройки → Обновления → Move Sensor BLE firmware → Установить (появляется, когда файлы прошивки изменились). Интеграция соберёт прошивку именно этого датчика и зальёт её при следующем пробуждении; ход виден на карточке обновления.
  • По Wi-Fi (WiFi включён): ESPHome Builder → Move Sensor BLE <ID> → Установка → В сети.

Если новая прошивка падает сразу после запуска, датчик автоматически возвращается к предыдущей.
